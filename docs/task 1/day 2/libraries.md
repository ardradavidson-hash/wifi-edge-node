## Required Libraries

The following libraries were installed through the Arduino IDE Library Manager for the environmental monitoring system:

| Library            | Purpose                                                  |
| ------------------ | -------------------------------------------------------- |
| DHT sensor library | Interface with the DHT22 temperature and humidity sensor |
| PubSubClient       | MQTT communication                                       |
| ArduinoJson        | Encoding and decoding JSON data                          |

### Installation Status
